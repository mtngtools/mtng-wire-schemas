# schemas/ — GENERATED, do not hand-edit

Every `*.schema.json` here is emitted from the Zod source in [`../src/`](../src/) by
`npm run generate`. Hand-edits are overwritten and will fail the drift gate
(`git diff --exit-code`) on the next regeneration.

The `.schema.json` file in this directory is a **stub** placeholder that fixes the layout
(one file per allow-listed message). The real generation command chain is finalized by the
acceptance spike tracked in `mtng-dotnet-mono` (foundation map); until it lands, treat the
stub as illustrative of the target shape, not as verified generator output.
